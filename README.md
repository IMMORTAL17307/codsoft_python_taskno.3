# Rock Paper Scissors Game ✊🖐️✌️

* **Name:** Ishant Khare
* **Company:** CodSoft

### 🎯 Objective
To build an interactive, logic-based game where a user plays Rock, Paper, Scissors against a randomized computer opponent.

### 🛠️ Tools Used
* Python

### 📝 Steps Performed
1. Captured user input and used the `random` module to determine the computer's choice.
2. Implemented complex conditional statements to evaluate the winner based on the rules of the game.
3. Developed a continuous loop allowing the user to play multiple rounds and track their total score.

### 💡 Outcome
An engaging console game demonstrating strong control flow, dynamic variable tracking, and user interaction in Python.
